# Committed scorecards

`fake/` is produced by `scripts/response_shape_scorecard.py run --fake-provider
--models response-shape/models.fake.json`. It costs $0, needs no credentials,
and is regenerated byte-for-byte by the test suite
(`test_committed_fake_scorecard_matches_a_fresh_fake_run`), so a change to the
metrics, the rollups or the accounting shows up as a diff here.

It is a PIPELINE proof, not a model result. The three fake models answer from
committed recorded envelopes with synthesised answer text and behave identically
under both shapes, so the paired section reports `unmeasured` by design — a fake
provider cannot carry a response-shape effect. Read the per-model rows as a
demonstration that faithful, terse and prose-wrapped answers land in different
columns; read nothing into the deltas.

Real-provider scorecards are NOT committed here: they go under
`benchmarks/repo-qa/.work/` (untracked), and their numbers are reported in the
task record with the model ids, the date and the cost.
